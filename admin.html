Password and access

Your owner password is managed on the Pi, not in this page.

Change ADMIN_PASSWORD in the Pi settings file and restart the service. Changing it signs out existing sessions.

Public site sync

Checking sync…

Setup help

In the Pi settings file, set GITHUB_SYNC_REPO, GITHUB_SYNC_BRANCH and GITHUB_SYNC_TOKEN, then restart the service. Sync sends your public collection to GitHub.

NAS and storage

Checking the NAS copy…

Video library on the NAS

Your videos in folders by category, named by post date and title, with a searchable index.html and index.csv at the top. The Pi's recovery copy is kept separately in _system (do not edit). Nothing is ever deleted from the NAS.

Checking the library…

Checking media storage…

Setup help

Set MIRROR_DIR to your mounted NAS folder in the Pi settings file. The service needs permission to write there. This is a second copy, separate from the checked media backup count.

Keep DATA_DIR on a permanent disk for your archive data. Set YOU2MP3_API_KEY for TikTok imports. Restart the service after changing the settings file.

Advanced: edit catalogue JSON
